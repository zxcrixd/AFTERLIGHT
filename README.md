# AFTERLIGHT

Небольшой 2D-платформер-выживалка на `pygame-ce`. Днём собирайте ресурсы и крафтите, ночью отбивайтесь от зомби, ставьте костры и не дайте голоду победить.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Сборка AppImage

Готовый файл `AFTERLIGHT-x86_64.AppImage` уже лежит в корне проекта. Чтобы
пересобрать его с нуля:

```bash
source .venv/bin/activate
pip install pyinstaller
./build_appimage.sh
```

Скрипт создаёт иконку, собирает onedir-версию через PyInstaller, складывает
`assets/` и `mods/` в AppDir и упаковывает всё в один AppImage. Для запуска:

```bash
chmod +x AFTERLIGHT-x86_64.AppImage
./AFTERLIGHT-x86_64.AppImage
```

Если в системе нет FUSE, используйте:

```bash
APPIMAGE_EXTRACT_AND_RUN=1 ./AFTERLIGHT-x86_64.AppImage
```

AppImage не может писать внутрь себя, поэтому сохранения, настройки и
пользовательские моды хранятся в `~/.local/share/afterlight` (или в
`$XDG_DATA_HOME/afterlight`). Переопределить папку можно переменной
`AFTERLIGHT_DATA_DIR`. Встроенный пример мода при этом остаётся доступен.

## Управление

| Действие | Клавиша |
| --- | --- |
| Движение | `A` / `D` или стрелки |
| Прыжок | `Пробел` |
| Пригнуться | `C` |
| Бег | `Shift` |
| Атака | `F` или ЛКМ |
| Собрать / использовать / поставить | `E` |
| Инвентарь и крафт | `I` или `Tab` |
| Хотбар | `1` … `6` |
| Пауза | `Esc` |
| Полный экран | `F11` |

Управление работает при любой раскладке клавиатуры, включая русскую: игра определяет физическую клавишу, а не введённый символ.

## Что есть в игре

- **Уникальная генерация мира**: у каждой новой игры свой сид, многослойный шум, четыре биома (лес, равнины, высокогорье, болото), разные наборы ресурсов и редкие древние руины. Сид сохраняется вместе с игрой и показывается в паузе.
- **Ресурсы**: деревья, валуны, кусты и грибы. У каждого узла несколько ударов и таймер восстановления.
- **Инвентарь на 24 слота** с хотбаром на 6 слотов и выбором предметов мышью.
- **Крафт**: факел, бинт, деревянный меч, каменный топор, кирка, копьё, костёр и костяное копьё.
- **Выживание**: здоровье, голод, выносливость, лечение у костра, регенерация при сытости.
- **Бой**: зомби с разным здоровьем/уроном днём и ночью, отбрасывание, дроп костей и волокна.
- **Постройки**: лагерный костёр освещает и лечит рядом.
- **Нормальный UI**: сердца, полосы голода/выносливости, часы, счётчик убийств, хотбар, всплывающие уведомления, подсказки взаимодействия, экран паузы и экран смерти.
- **Сохранение/загрузка** прогресса: в исходниках — `saves/game.json`, в AppImage — `~/.local/share/afterlight/game.json`.
- **Настройки**: язык (RU/EN), громкость музыки и звуков, полноэкранный режим.
- **Моды на Python**: свои предметы, рецепты, ресурсы, иконки, события и данные в сохранении. Подробности — в [`mods/README.md`](mods/README.md), готовый пример — в `mods/example_mod`.

## Моды

Положите мод в `mods/` — папкой с `mod.py` или одиночным `.py`-файлом. В комплекте уже есть пример `mods/example_mod`, который добавляет кристаллы, кристальный меч и светящиеся жилы.

```python
def setup(api):
    api.register_item(
        "my_item", "Мой предмет", "My Item",
        description_ru="Добавлен модом.",
        description_en="Added by a mod.",
    )
```

Загруженные моды видны в меню паузы, а ошибки выводятся в консоль и уведомлением. Моды выполняют обычный Python-код — устанавливайте только доверенные.

## Мобильная версия

В папке [`mobile/`](mobile/README.md) лежит заготовка для Android (Buildozer /
python-for-android) и заметки по iOS. При запуске на Android/iOS или с
`AFTERLIGHT_MOBILE=1` поверх игры появляются сенсорные кнопки: движение,
прыжок, атака, действие, инвентарь и пауза. Меню и оверлеи работают по тапу.

Предпросмотр на компьютере:

```bash
AFTERLIGHT_MOBILE=1 python main.py
```

Сборка Android:

```bash
cd mobile
./prepare_android.sh
buildozer -v android debug
```

Подробности, зависимости и ограничения — в [`mobile/README.md`](mobile/README.md).
